Сайт Минск — сайт «Замена венцов», Минск и Минская область
==========================================

ЧТО ВНУТРИ
  index.html, privacy.html   страницы
  css/style.css, js/main.js  стили и скрипты (квиз, меню, галерея)
  api/send.js                отправка заявок в Telegram для Vercel (Serverless Function)
  api/send.php               то же самое для обычного хостинга с PHP
  server.js, start.bat       локальный запуск для проверки (на Vercel и хостинг не нужны)
  check-telegram.mjs/.bat    проверка бота и тестовое сообщение
  .htaccess                  настройки Apache (адрес /api/send, защита служебных файлов)
  vercel.json, package.json  заголовки безопасности, кэш, настройки Node
  set-domain.mjs             подстановка домена при деплое (запускается сама)
  sitemap.xml, robots.txt    для поисковиков

ТОКЕН БОТА И ВАШ ID УЖЕ ВПИСАНЫ В КОД (серверные файлы, в браузер не попадают):
  api/_config.js   для Vercel
  api/config.php   для обычного хостинга с PHP
  Менять бота или получателя нужно в этих двух файлах. Получателей может быть несколько.
  ВАЖНО: так как токен лежит в коде, репозиторий на GitHub должен быть ПРИВАТНЫМ.
  Если токен засветился, у @BotFather выполните /revoke и впишите новый в оба файла.
  Бот должен получить от вас /start, иначе Telegram не даст ему писать.

ПРОВЕРКА У СЕБЯ НА КОМПЬЮТЕРЕ (нужен Node.js, https://nodejs.org)
  ВАЖНО: если открыть index.html двойным кликом (адрес file:///...), заявки отправляться НЕ БУДУТ:
  у файла нет сервера, браузер блокирует запрос /api/send. Это нормально, так работают все сайты.
  Как проверить правильно:
    1. Двойной клик по check-telegram.bat: проверит токен и ID и пришлёт тестовое сообщение в Telegram.
       Если не пришло, программа напишет причину и что сделать.
    2. Двойной клик по start.bat: запустит сайт на http://localhost:3000 (откроется сам).
       Пройдите квиз. Заявка придёт в Telegram, ошибки (если есть) будут видны в чёрном окне.
  (то же командами: node check-telegram.mjs   и   node server.js)

ЗАПУСК НА VERCEL (демо для клиента)
  1. Загрузите папку в ПРИВАТНЫЙ репозиторий GitHub так, чтобы index.html лежал в КОРНЕ репозитория.
     Подключите репозиторий в Vercel (Framework Preset: Other) и нажмите Deploy. Больше ничего не нужно.

ХОСТИНГ У ХОСТЕРА (боевой сайт, PHP + Apache)
  1. Загрузите ВСЁ содержимое папки сайта в корень сайта (public_html / www) по FTP или через файловый менеджер,
     включая скрытые файлы .htaccess (в корне и в папке api).
  2. Включите PHP 7.4 или новее и расширение curl (обычно включено по умолчанию).
  3. Подключите SSL-сертификат (Let's Encrypt), затем в .htaccess раскомментируйте три строки принудительного HTTPS.
  4. Пройдите квиз на сайте. Если заявка не пришла, посмотрите журнал ошибок PHP в панели хостинга:
     там будет причина (неверный токен/ID, не нажат /start, хостинг блокирует исходящие запросы к api.telegram.org —
     в этом случае напишите в поддержку хостера, чтобы разрешили исходящие соединения).
  5. Файлы api/send.js, api/_config.js, package.json, vercel.json на хостинге не нужны, их можно не загружать.
     Нельзя удалять api/send.php, api/config.php, api/.htaccess и .htaccess.

ДОМЕН
  На Vercel подставляется АВТОМАТИЧЕСКИ при каждом деплое (canonical, og:url, микроразметка,
     sitemap.xml, robots.txt). Ничего запускать не нужно:
       - пока домена нет, используется адрес проект.vercel.app;
       - подключили свой домен (Vercel -> Settings -> Domains) -> сделайте Redeploy, и он подставится сам.
     Если нужен именно вариант с www (или другой), добавьте переменную SITE_DOMAIN = www.example.by.
     Подключайте домен так, чтобы второй вариант (с www или без) перенаправлял на основной:
     в Settings -> Domains у второго домена выберите Redirect to ...
  НА ОБЫЧНОМ ХОСТИНГЕ домен автоматически не подставляется. ПЕРЕД загрузкой по FTP выполните один раз
     на своём компьютере в папке сайта:  node set-domain.mjs ваш-домен.by
     (нужен Node.js) или откройте в блокноте index.html, privacy.html, sitemap.xml, robots.txt
     и заменой «ВАШ-ДОМЕН» -> «ваш-домен.by» впишите адрес. Это нужно для canonical, sitemap и поисковиков.

ПЕРЕД ПУБЛИКАЦИЕЙ
  - В privacy.html укажите оператора (название/ФИО, УНП, адрес).

ПРОВЕРКА ЗАЯВКИ
  Откройте сайт, пройдите квиз до конца (после загрузки страницы подождите 3 секунды — это
  защита от ботов), в Telegram должно прийти сообщение. Если нет:
    - на Vercel: Vercel -> Logs -> функция /api/send; на хостинге: журнал ошибок PHP в панели.
      Там написана причина: Telegram 403/400 = не нажали /start у бота или неверный ID/токен;
    - при ошибке посетитель увидит кнопки «Отправить ещё раз», «Написать в Telegram» и «Позвонить»,
      так что заявка не потеряется.
  Защита: скрытое поле-ловушка, задержка отправки, не более 5 заявок с одного IP за 10 минут,
  приём запросов только с вашего домена, экранирование текста для Telegram.
